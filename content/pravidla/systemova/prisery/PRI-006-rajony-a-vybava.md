# Rajóny příšer a výbava

## Rajóny (přidělené lokace)

Příšery mají přidělené lokace (rajóny), po kterých se pohybují. Každá příšera dostane **mapu**, aby věděla, kde se lokace nacházejí.

## Rozhazování herních předmětů

V průběhu hry příšery doplňují své lokace **herními předměty**, které mohou hrdinové sbírat:

- Umísťujte předměty **kolem lokace**, viditelně, ale nikoliv nutně nápadně
- Děti si mohou trochu potrápit zrak
- Konkrétní počty k rozhazování dostanete před hrou

**Pozor**: Hráči sledují příšery, když rozhazují poklady, a rovnou si je berou! Buďte diskrétní.

## Výbava příšery

Každá příšera s sebou dostane:

| Předmět | Popis |
|---------|-------|
| Maska | Rozpoznávací znak příšery |
| Karty příšer | Statistiky nestvůr |
| Pravidla pro příšery | Tento dokument |
| Plná pravidla | Kompletní pravidla hry |
| Balíček karet setkání | Pro losování skupinek |
| Balíček karet odměn | Odměny za souboje |
| Kostky s podložkou | Pro souboje |
| Diamanty (zkušenosti) | Černý diamant = 5 zk, ostatní = 1 zk |
| Groše | Do pokladů k rozhazování |
| Životy | Kartičky životů pro správu soubojů |
